# Distributed Flocking - ESP32 Drone Swarm

## Project Goals
- Run a simulated drone on each ESP32 using FreeRTOS tasks
- Exchange neighbor state over LoRa, publish state via MQTT over Wi-Fi
- Implement Reynolds-style flocking (cohesion, alignment, separation)
- Add a basic security layer (AES-CMAC tag) and design adversarial tests
- Measure timing, stability, availability, and energy

## System Design: Core FreeRTOS Tasks
### Physics Task (50 Hz, high priority)
- Integrate position (x, y, z), velocity (vx, vy, vz), yaw
- Clamp motion to simulation boundaries
- Apply command generated by flocking task
- Flocking Task (10 Hz, medium priority)
- Read neighbor table + own state
- Compute Reynolds rules
- Output commanded velocity + yaw rate
- Radio I/O Task (2–5 Hz, medium/low)
- Encode + broadcast LoRa packet
- Receive packets → update neighbour table (timestamps, seq, expiry)

### Telemetry Task (2–5 Hz, low)
- Publish JSON state via MQTT
- Handle Wi-Fi reconnect logic

### Data Structures
- '''drone_state_t'''
- '''neighbour_t'''
- '''neighbour_table[]'''
- '''flock_cmd_t'''
